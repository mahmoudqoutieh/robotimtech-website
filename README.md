# Robotim tech website

Static, dependency-free site (HTML, CSS and JS inline). Arabic and English, RTL aware.

- Entry: `index.html`
- Assets: `img/`, `favicon.svg`
- Contact form: set `WA` (WhatsApp number, digits only) and `MAIL` at the top of the inline script in `index.html`.
- Deploy: any static host (Cloudflare Pages, Netlify, Vercel). Build command: none. Output directory: `/`.
- Domain: robotimtech.com
